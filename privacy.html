プライバシーポリシー

最終更新日：2026年10月14日

  • mac-backup は、開発者本人の Google ドライブに、本人の Mac のファイルをアップロードするためだけに使用します。
  • 利用する権限は Google ドライブの drive.file（このアプリ自身が作成したファイルのみ）に限られます。それ以外のファイルにはアクセスしません。
  • 取得したデータや認証情報を、開発者以外の第三者に送信・共有・販売することはありません。データは利用者本人の Mac と Google ドライブにのみ保存されます。
  • Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

Privacy Policy (English)

  • mac-backup is used solely to upload the developer's own Mac files to the developer's own Google Drive.
  • It only requests the drive.file scope (files created by this app). It does not access any other files.
  • No data or credentials are sent, shared, or sold to any third party. Data is stored only on the user's own Mac and Google Drive.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
